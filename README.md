# O Método Paulo Freire

Mapa mental interativo sobre o livro *O que é o Método Paulo Freire*, de Carlos Rodrigues Brandão. O projeto organiza conceitos, conexões e imagens relacionadas ao método de forma explorável.

## Como abrir

O projeto é estático e não requer instalação de dependências. Abra o arquivo `index.html` em um navegador ou publique os arquivos em um servidor estático.

## Navegação

- Arraste para mover o mapa.
- Use a roda do mouse, pinça ou os controles laterais para aproximar e afastar.
- Selecione um cartão para abrir seus desdobramentos e a ficha explicativa.
- Use o botão de PDF para baixar uma versão com visão geral, tópicos detalhados e referências.

## Estrutura

- `index.html` — estrutura da aplicação.
- `css/style.css` — estilos e responsividade.
- `js/app.js` — dados do mapa, interações e exportação em PDF.
- `referencias/` — material de referência do trabalho.

## Referência principal
